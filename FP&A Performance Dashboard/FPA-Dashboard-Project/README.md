# FPA-Dashboard-Project

Bundle of FP&A deliverables produced from `fpa_variance_data_monthly.csv`.

## Contents

| File | Description |
|---|---|
| `fpa_variance_data_monthly_cleaned.csv` | Cleaned source data (96 rows, 8 departments × 12 months) |
| `fpa_performance_dashboard.xlsx` | 4-tab Excel model (Dashboard / Raw Data / Monthly P&L / 3-Month Forecast) |
| `charts/01_budget_vs_actual_by_month.png` | Clustered bar — Budget vs Actual by month |
| `charts/02_revenue_trend_mom.png` | Line chart — monthly revenue with MoM % labels |
| `charts/03_variance_waterfall.png` | Waterfall — Budget Total → dept variances → Actual Total |
| `charts/04_kpi_summary.png` | KPI summary card image (Revenue / Expenses / Net Profit / Variance %) |

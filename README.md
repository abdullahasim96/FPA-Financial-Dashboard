# FP&A Financial Performance Dashboard

Most analytics projects live in a tutorial. This one doesn't.

This project replicates the kind of financial analysis I've done 
professionally — budget vs. actual variance, KPI tracking, and 
forward-looking forecasts — but built end-to-end from a real dataset 
using SQL and Excel.

---

## What I Built and Why

I wanted to show what FP&A work actually looks like in practice, not 
just a cleaned-up dataset with a few charts on top. So I took a real 
budget vs. actual dataset, ran proper SQL analysis on it, and built an 
Excel model that mirrors what a finance team would actually use in a 
monthly close cycle.

---

## What This Covers

- Budget vs. actual variance by month — where did we overspend and by how much
- Month-over-month revenue trend — is the business growing or declining
- KPI summary — total revenue, expenses, net profit, and variance % in one view
- 3-month rolling forecast — where are we headed based on recent performance
- Variance waterfall — breaking down what actually drove the numbers

---

## Tools Used

- **SQL** — data extraction, variance queries, rolling averages
- **Excel** — P&L model, forecast tab, variance calculations
